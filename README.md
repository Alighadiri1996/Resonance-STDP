# AHAAA 2025 – Figure Generation Code

This repository contains Python scripts used to generate Figures 1–6 
from the paper **"Analysis of High-Accuracy Adaptive Algorithms (AHAAA), 2025"**.

## Contents
- `/scripts`: Python scripts for each figure.
- `/results`: Output images and data.
- `requirements.txt`: Dependencies list.

## Usage
```bash
pip install -r requirements.txt
python scripts/AHAAA_2025_Fig1.py
